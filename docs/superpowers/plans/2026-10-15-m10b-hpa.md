# M10b HorizontalPodAutoscaler 与 scale 子资源实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供以下能力：
- Deployment、ReplicaSet、StatefulSet 的 `scale` 子资源（autoscaling/v1 Scale）。
- autoscaling/v2 HorizontalPodAutoscaler 与 HPA 控制器，按 M10a 的资源指标自动扩缩。
- `kk get/describe hpa`、`kk autoscale`，`kk scale` 改走 scale 子资源。

**Architecture:**

- **API Server**：`{deployments,replicasets,statefulsets}/{name}/scale` 支持 GET/PUT/PATCH。
  - GET 由对象的 `spec.replicas`、`status.replicas` 与 selector 生成 Scale。
  - PUT/PATCH 只改 `spec.replicas`（经对象的 Strategy 校验）；Scale 中的 resourceVersion 是前置条件。
  - discovery 列出 `*/scale`。
- **API**：`pkg/apis/autoscaling/v2`。
  - **默认值**：minReplicas 1；没有 metrics 时为 CPU 80%；给了 behavior 时补默认规则。扩容规则为 0 秒稳定窗口，每 15 秒 4 个 Pod 或 100%（取较大者）；缩容规则为 300 秒稳定窗口，每 15 秒 100%。
  - **校验**：文案取自 AKS 实测。只支持 Resource 与 ContainerResource 两类指标（cpu、memory），因为没有 custom/external metrics API。
- **控制器**：`pkg/controller/podautoscaler`，按 k8s 的 `horizontal.go` 与 `replica_calculator.go` 实现。
  - **周期**：默认每 15 秒同步一次（`MINI_HPA_SYNC_PERIOD`），只有 spec 变化才立即同步。
  - **取目标**：GET 目标的 scale。失败时 AbleToScale 为 False/FailedGetScale，并发 FailedGetScale 事件。
  - **按指标出提案**：经 metrics.k8s.io 取 Pod 指标，以 requests 计算利用率或平均值，容忍度 0.1。
    - 未就绪 Pod 按 k8s 规则处理：CPU 有 5 分钟初始化期、30 秒初始就绪延迟。
    - 保守估算：缺指标的 Pod 在缩容时按 100% 计，在扩容时按 0 计。
  - **合并提案**：多个指标取最大值；全部失败时 ScalingActive 为 False，并发 FailedComputeMetricsReplicas 事件。
  - **归一化**：
    - 没有 behavior 时按 legacy 规则：5 分钟缩容稳定窗口，扩容上限 `max(2×当前, 4)`。
    - 有 behavior 时用其中的双向稳定窗口与 policies（Pods/Percent，Max/Min/Disabled）。
  - **写回**：
    - 改目标时 PUT scale，发 SuccessfulRescale `New size: N; reason: ...` 事件。
    - status 写 currentReplicas、desiredReplicas、currentMetrics、lastScaleTime、observedGeneration，以及 AbleToScale、ScalingActive、ScalingLimited 三个 condition。
- **kk**：
  - `get hpa` 的列为 NAME REFERENCE TARGETS MINPODS MAXPODS REPLICAS AGE，TARGETS 如 `cpu: 201%/50%`，最多显示两项，其余记为 `+ N more...`。
  - `describe hpa`：Metrics、Behavior、Conditions。
  - `autoscale TYPE NAME --max N [--min N] [--cpu-percent N | --cpu N%|QUANTITY] [--name]`，输出 `horizontalpodautoscaler.autoscaling/NAME autoscaled`。

## AKS 实测（mini-k8s-probe-m10b、mini-k8s-probe-m10b2 命名空间）

| 项目 | 结果 |
| --- | --- |
| scale 子资源 | `{"kind":"Scale","apiVersion":"autoscaling/v1","metadata":{name,namespace,uid,resourceVersion,creationTimestamp},"spec":{"replicas":1},"status":{"replicas":1,"selector":"app=web"}}`；`kubectl scale` 发 PATCH `.../scale` |
| `kubectl autoscale` | `horizontalpodautoscaler.autoscaling/web autoscaled`；`--max` 小于 `--min` 时报 `--max=MAXPODS must be larger or equal to --min=MINPODS, max: 1, min: 3` |
| `get hpa` | 刚创建时为 `web Deployment/web cpu: <unknown>/50% 1 3 0`，之后为 `cpu: 201%/50% 1 3 3`；只用平均值时显示 `memory: <unknown>/100Mi` |
| 扩容 | 每个 Pod 约 201% 对 50%：`New size: 3; reason: cpu resource utilization (percentage of request) above target`；ScalingLimited 为 True/TooManyReplicas |
| 缩容 | `New size: 1; reason: All metrics below target`；ScalingLimited 为 True/TooFewReplicas `the desired replica count is less than the minimum replica count` |
| conditions | AbleToScale：SucceededGetScale、ReadyForNewScale（`recommended size matches current size`）、SucceededRescale（`the HPA controller was able to update the target scale to 1`）、FailedGetScale；ScalingActive：ValidMetricFound、FailedGetResourceMetric（`the HPA was unable to compute the replica count: failed to get cpu utilization: did not receive metrics for targeted pods (pods might be unready)`） |
| 事件 | FailedGetResourceMetric：`failed to get cpu utilization: unable to get metrics for resource cpu: no metrics returned from resource metrics API`；FailedComputeMetricsReplicas：`invalid metrics (1 invalid out of 1), first error is: failed to get cpu resource metric value: ...` |
| 目标缺失 | AbleToScale 为 False/FailedGetScale，`the HPA controller was unable to get the target's current scale: deployments.apps "ghost" not found`；Warning FailedGetScale `deployments.apps "ghost" not found` |
| 校验 | `spec.maxReplicas: Invalid value: 2: must be greater than or equal to \`minReplicas\``、`spec.metrics[0].resource.target.averageUtilization: Invalid value: 0: must be greater than 0`、`spec.maxReplicas: Invalid value: 0: must be greater than 0`、`spec.scaleTargetRef.apiVersion: Invalid value: "": apiVersion must specify API group` |
| behavior 默认值 | 见上文"默认值" |
| describe | `resource cpu on pods  (as a percentage of request):  201% (201m) / 50%`、`Deployment pods: 3 current / 3 desired`、Conditions 表 |
