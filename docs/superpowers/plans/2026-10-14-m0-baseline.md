# M0 工程基线 Implementation Plan

> **注：** 2026-10-15 代码目录已按 Kubernetes 的结构重构（`internal/` → `pkg/` 等），本文中的路径为当时的历史路径；当前结构见 [v2 设计规格 §15](../specs/2026-10-14-mini-k8s-v2-design.md)。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v1 代码上修掉不会被 M1 重构吞掉的问题，把开发、测试和文档基线切换到 Linux。

**Architecture:** 只做局部修改：仓库属性、Compose 参数、kubelet 状态写入条件、API 错误信息、
`kk` 启动代码、Makefile 与文档。不改变 v1 的 API 形态（M1 会整体替换）。

**Tech Stack:** Go 1.23+、etcd v3.5.17、Docker Engine + Compose v2、GNU Make。

## Global Constraints

- 所有构建与测试在 Linux（WSL2 Ubuntu 24.04）执行；文档只写 Linux 命令。
- 不引入新的 Go 依赖。
- 只清理本项目拥有的容器，不执行全局 prune。
