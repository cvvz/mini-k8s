# M10a 资源指标、metrics-server 与 kk top 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 Kubernetes 的资源指标管道实现：
- kubelet 暴露 `/metrics/resource`。
- metrics-server 插件抓取各节点，计算 CPU 速率，提供 `metrics.k8s.io/v1beta1`（NodeMetrics、PodMetrics）。
- API Server 像 kube-aggregator 一样把该组代理给 metrics-server。
- `kk top nodes|pods`。

这是 M10b HPA 的数据来源。

**Architecture:**

- **kubelet**（`pkg/kubelet/metrics`、`kuberuntime/stats.go`）：
  - 容器数据：经 CRI `ListContainers`（运行中）与 `ListContainerStats` 取累计 CPU 与 working set。
  - 节点数据：读节点容器自身的 cgroup v2 目录。CPU 取 `cpu.stat` 的 `usage_usec`；内存为 `memory.current - inactive_file`。
  - 输出 Prometheus 文本，指标族与 kubelet 相同：container/pod/node 的 `*_cpu_usage_seconds_total`、`*_memory_working_set_bytes`、`container_start_time_seconds`、`resource_scrape_error`。
- **metrics-server**（`pkg/metricsserver`，`mini metrics-server`，`build/manifests/addons/metrics-server.yaml`）：
  - 每个分辨率周期（插件中为 10s，默认 15s）并发抓取所有节点。
  - 为每个节点和容器保留上一次和最近一次采样，CPU 用量 = ΔCPU/Δt。容器重启、CPU 回退时不出数据。
  - Pod 的每个容器都有两次采样才返回该 Pod。
  - 用 informer 补全标签并过滤 selector。
- **API Server**（`pkg/apiserver/aggregator.go`）：
  - `/apis` 列出 `metrics.k8s.io`。
  - `/apis/metrics.k8s.io/...` 的 GET 请求带上 API Server 自己的 token，转发到 `kube-system/metrics-server` Endpoints 的一个就绪地址。
  - 没有可用端点或连接失败时，返回 503 `the server is currently unable to handle the request`。
  - 新增 `nodes/{name}/proxy/{path}` 子资源，GET 转发到 kubelet。
- **kk**：
  - `kk top nodes|pods [NAME] [-l] [--containers] [--sort-by cpu|memory]`，`-A` 显示 NAMESPACE 列。
  - API 不可用时报 `Metrics API not available`。
  - `kk api-resources` 遇到不可用的组时先打印其余各组，再报错（与 kubectl 相同）。
- **resource.Quantity**：支持 `n`、`u` 后缀，新增 `NewNanoQuantity`、`NewBinaryQuantity`（metrics API 的 `117586291n`、`131288Ki` 写法）。
- **metav1.Duration**：新增，按 `1m0.348s` 的格式编码。

## AKS 实测（只读）

| 项目 | 结果 |
| --- | --- |
| `kubectl top nodes` | `NAME CPU(cores) CPU(%) MEMORY(bytes) MEMORY(%)`，如 `330m 8% 2907Mi 21%`（CPU 取毫核，内存取 Mi，百分比为占 allocatable 的比例） |
| `kubectl top pods` | `NAME CPU(cores) MEMORY(bytes)`；`-A` 加 NAMESPACE 列；`--containers` 列为 `POD NAME CPU(cores) MEMORY(bytes)` |
| 命名空间内没有指标 | `No resources found in default namespace.` |
| api-resources | `nodes metrics.k8s.io/v1beta1 false NodeMetrics`、`pods ... true PodMetrics` |
| NodeMetrics | `{"metadata":{name,creationTimestamp,labels},"timestamp","window":"1m0.348s","usage":{"cpu":"307831245n","memory":"2987404Ki"}}` |
| PodMetrics | `containers[{name,usage{cpu,memory}}]`，含 Pod 标签 |
| discovery | `APIResourceList` 中 nodes/pods 的 verbs 为 get、list，`singularName` 为空 |
| 不存在的对象 | `pods "x" not found`、`node "x" not found` |
| APIService | `v1beta1.metrics.k8s.io` → `kube-system/metrics-server:443` |
| kubelet `/metrics/resource` | 带 HELP、TYPE 的 Prometheus 文本，样本带毫秒时间戳，如 `container_cpu_usage_seconds_total{container=…,namespace=…,pod=…} 3.851144 1792044695747` |
